# 随声提词 · iPhone 验证版

原生 SwiftUI iPhone 应用。用于验证“苹果原生相机录像 + 画中画提词 + 后台语音识别”的兼容性。

## 已实现

- 完整逐字稿编辑、本地自动保存。
- 系统画中画提词，可按系统支持方式拖动、缩放。
- 当前句高亮、手动上一句/下一句、匀速滚动、字号与速度调节。
- 中文系统语音识别，优先设备端；不支持设备端时会明确提示在线识别。
- 保守的局部文本匹配：候选不明确时保持位置，限定附近段落避免远距离跳稿。
- 麦克风中断日志。相机抢占麦克风时停止跟随，不伪装成持续识别。

## 尚未实现或保证

- 当前算法为文字相似度匹配，不是 AI 语义理解；不能保证大幅改写、长时间发挥后仍能跟上。
- 语音识别结束/报错后需要重新开启，尚未做连续会话接续。
- 真正透明的跨 App 窗口、任意位置停放和自定义窗口触摸控件不属于系统画中画提供的能力。
- 后台时钟刷新及原生相机与语音采集共存，必须经过真机拍摄验证。
- 完整商业产品的隐私政策、上架资料、异常恢复尚未完成。

## 真机验证步骤

1. 编辑一段稿子，允许系统麦克风和语音识别权限。
2. 开启语音跟随，在应用内照读、插入一段无关内容，再回到下一句。
3. 开启悬浮，切换到苹果相机，用前置竖屏录制 30 秒。
4. 检查悬浮是否保留、是否继续刷新；检查视频是否正常收音且不含提词窗。
5. 返回提词器查看日志，确认相机是否中断了麦克风。
6. 若语音中断，关闭语音跟随后测试匀速悬浮；不能据此声称原生相机语音跟随可用。

## 构建

打开 FloatPrompt.xcodeproj，选择自己的开发团队和 iPhone 后运行。项目生成配置在 project.yml。
